# Pokémon Champions 速度線研究所

用繁體中文查看《Pokémon Champions》的速度比較。選擇對手和自己的隊伍，就能在同一張圖上看出誰比較快。

## 功能介紹

- **速度線比較**：顯示對手從減速到極速的速度範圍，並標出我方寶可夢的速度位置。
- **我的隊伍**：加入最多六隻寶可夢，設定速度 SP、性格、速度階級、特性加速，以及講究圍巾或黑色鐵球。
- **對戰場況**：分別設定雙方順風；開啟戲法空間後，速度線會讓較慢的寶可夢排在上方，並顯示對應的背景效果。
- **搜尋與篩選**：可用中文、英文或圖鑑編號搜尋，也能依屬性、世代和 Mega 初登場作品篩選。
- **隊伍匯入**：貼上 PokePaste 隊伍文字，自動帶入可辨識的寶可夢與速度設定，統一以 50 等計算。
- **跨裝置版面**：寬螢幕並排顯示速度線與搜尋；窄螢幕可切頁，手機也能左右滑動。隊伍設定會保存在目前使用的裝置上。
